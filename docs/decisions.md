# Журнал решений

Сюда записываем решения, которые не очевидны из кода: выбор технологий, форматы, отказ от подходов, договорённости между участниками. Цель: чтобы никто (включая Claude на другой машине) не обсуждал одно и то же дважды.

## Правила

- Записи только **добавляются в конец** файла. Старые не редактируются: если решение изменилось, пишем новую запись со ссылкой на старую (`Отменяет: ...`).
- Запись делается в том же коммите, что и изменение, к которому она относится.
- Дата в формате `ГГГГ-ММ-ДД`. В поле «Кто» GitHub-логин (или имя) того, кто принял/записал решение.
- Если при пуше конфликт из-за одновременных записей, оставить обе.

## Шаблон записи

```markdown
### ГГГГ-ММ-ДД. Короткий заголовок решения
- **Кто:** @login
- **Статус:** принято | предложено | отменено
- **Контекст:** какая была проблема или вопрос.
- **Решение:** что решили.
- **Почему / альтернативы:** что ещё рассматривали и почему не выбрали.
- **Последствия:** что теперь нужно делать или чего нельзя делать.
```

## Записи

### 2026-10-03. Совместная работа с нескольких компьютеров и аккаунтов
- **Кто:** @AlexKlush
- **Статус:** принято
- **Контекст:** над проектом работают несколько человек с разных машин и под разными GitHub-аккаунтами. Сессии Claude Code на разных машинах не разделяют историю чата.
- **Решение:** единственный общий источник контекста: этот репозиторий. Правила работы зафиксированы в `CLAUDE.md`, решения ведутся здесь. Участники с правами write коммитят в `main`.
- **Почему / альтернативы:** общий чат между машинами технически невозможен. Вариант «все только через PR» надёжнее против конфликтов, но тяжелее для небольшой команды; оставлен как правило для крупных и рискованных изменений.
- **Последствия:** перед каждым пушем `git pull --rebase --autostash origin main`; `--force` в `main` запрещён; секреты и тяжёлые данные в репозиторий не попадают. Если конфликты станут частыми, пересмотреть в пользу веток и PR.

### 2026-10-03. Журнал всех запросов с каждой машины в `docs/log/`
- **Кто:** @AlexKlush
- **Статус:** принято
- **Контекст:** нужно, чтобы сохранялись все просьбы пользователей с обоих компьютеров и что по ним изменено; сессии Claude на разных машинах не видят чужой чат.
- **Решение:** hook `UserPromptSubmit` (`scripts/log_prompt.py`, подключён в `.claude/settings.json`) дословно дописывает каждый запрос в `docs/log/ГГГГ-ММ-ДД_<git-user>_<машина>.md`; Claude после задачи дописывает под запросом `**Сделано:**`. Файл коммитится вместе с работой.
- **Почему / альтернативы:** положиться на то, что Claude сам запишет запрос, ненадёжно. Один файл на человека+машину+день исключает конфликты слияния. Один общий файл или файл на запись отвергнуты: первый конфликтует, второй даёт сотни мелких файлов. Токены (`ghp_`, `sk-`, `AKIA`, приватные ключи) маскируются автоматически.
- **Последствия:** перед пушем нужен `--autostash` (hook оставляет незакоммиченный файл). Запросы пишутся дословно, поэтому в чат нельзя вставлять секреты. Нужен `python3` на каждой машине.

### 2026-10-03. Репозиторий переведён в private
- **Кто:** @AlexKlush
- **Статус:** принято
- **Контекст:** репозиторий был публичным, а журнал запросов содержит дословные сообщения.
- **Решение:** видимость `private`. Доступ сохранён у коллабораторов с правами write (на момент записи: AlexKlush, Sssofa1006).
- **Почему / альтернативы:** вариант «публичный + только краткие сводки» отвергнут ради полноты истории.
- **Последствия:** если репозиторий когда-нибудь станет публичным, сначала убрать `docs/log/` и `.claude/settings.json` и проверить историю на секреты. Новым участникам нужно принять приглашение коллаборатора.
